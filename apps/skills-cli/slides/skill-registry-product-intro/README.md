# Skill Registry Product Intro Deck

## Run locally

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

## Export PDF

```bash
pnpm add -D playwright-chromium
pnpm run export
```

The deck source lives in `slides.md`.
Shared presentation styling lives in `styles.css`.
Reusable diagram components live in `components/`.
