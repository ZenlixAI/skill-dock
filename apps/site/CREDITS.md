Interaction patterns and visual primitives were adapted from these component libraries:

- [Magic UI](https://magicui.design) (MIT) for the animated grid pattern, border beam, marquee, segmented tabs, and terminal treatment.
- [React Bits](https://reactbits.dev) (MIT with Commons Clause) for the blur-text reveal, magnet, count-up, and spotlight-card interactions. The Commons Clause restricts selling or redistributing the components themselves. The site uses adapted implementations, not a component package.
